# Back-cover prototype

Question: which back-cover information hierarchy should enter the canonical
SVG/PDF cover pipeline?

Run from the repository root:

```sh
uv run --locked python -m http.server 8000
```

Then open `http://localhost:8000/prototypes/back-cover-prototype/?variant=A`.
Use the floating arrows or keyboard left/right keys to compare A and B.
Delete the losing variants after a direction is selected.
