title: The Ten-Minute Question
byline: The Editors
---

The code can arrive in twenty minutes while the feature waits.

Coding was only 25–50% of the old schedule. Before it, people aligned on what to build and how it should fit the system. After it, they reviewed, reworked, tested, and verified. An agent that writes code faster reaches those queues sooner.

Ask where a mistake will cost most. A loose prompt leaves much of the expected pain in place. A careful specification lowers that risk, but writing one can consume the time saved. Spend attention where it removes the most expensive uncertainty, then stop before planning becomes a second project.

Expertise now includes knowing which unanswered question deserves ten minutes and which can wait until the next level down. Move the bottleneck and the work moves with it. A blank file can block the factory. More often, the decision before it holds the line.
