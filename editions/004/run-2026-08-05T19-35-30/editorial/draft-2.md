title: The parts that remember
byline: The Editors

A server can pause a request with `resultType: "input_required"`, return questions plus a `requestState`, and let any instance resume when answers come back. The work survives because its state travels with the request instead of hiding in a connection.

That detail offers a test for the systems around a model. An eval earns its keep only when a failed result changes the next edge: an empty search must stop the agent from inventing museum hours. Planning earns leverage when it removes rework before code begins. In both cases, a record becomes an instruction.

The intrusion shows what happens when records do not join. Credentials, tokens, and thousands of probes moved through ordinary services; the few successful paths disappeared inside the many dead ones. Defenders found the route only after reconstructing events across layers. The lesson is operational: make attempts, permissions, and stopping conditions visible where the next action can use them.

A model may forget, a network may reconnect, and a team may change tools. Give the next request the evidence of the last one, and the system has a chance to change its mind.
