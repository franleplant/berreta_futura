Twenty-two thousand five hundred and eighty. That’s how many GPT-2 (2019) models fit inside KimiK3 (2026). We scaled up by a factor of 22,580 in seven years. But is it just... scale?

At every token, a language model must decide what remains available when memory fills. KimiK3’s answer is to keep a bounded recurrent state and retrieve outside it when necessary. Each step answers a different failure: the cache grows, the fixed state interferes, a replacement rule cannot forget generally, and depth can dilute its own history.

GPT-2’s decoder-only transformer reads left to right. Token embeddings identify each input and positional embeddings mark its place. In each block, causal self-attention lets a position look only at earlier tokens, while an MLP, a small feed-forward network, transforms the result; residual connections add each block’s output back to its input. The final representation becomes scores over possible next tokens. During one-token-at-a-time generation, the model computes representations for every input position even though only the last position’s scores choose the next token. Keeping the earlier matching key vectors and content value vectors avoids repeating those projections. This retained history forms the KV cache. It holds N−1 tokens and can become large enough to bottleneck memory bandwidth. The baseline model has about 124 million parameters; KimiK3 reaches 2.8 trillion parameters.

Linear attention addresses the cache’s growth. The paper’s O(N²) framing threw me off. Softmax attention compares each query vector, what the current position is asking for, with every key vector, what a stored position offers, then applies its exponential to turn those comparisons into weights. Linear attention applies a feature map such as ELU+1 to queries and keys separately, making them non-negative before they interact. Because the product can be regrouped, the growing collection of key and value vectors folds into a fixed D×D state. At a high level, both methods make scores non-negative, divide by their sum, and compute a weighted average of the values. Linear attention pays for the fixed state with a less expressive approximation of the softmax kernel, so practical accuracy loss depends on the architecture and workload. At the time, training commonly materialized the full N×N attention matrix, FlashAttention did not yet exist, and reference implementations often recomputed token history without a KV cache.

Compression leaves a second problem: interference. A finite D×D memory gives every association the same space, so additive updates eventually overlap, especially when the sequence is much longer than D. DeltaNet makes the write corrective. It reads what the current key retrieves, subtracts that from the value it wants to store, and adds a learned fraction of the difference. In the implementation, `beta = sigmoid(w_beta(x))` is a per-token write strength. With a normalized key, `beta = 1` gives exact replacement; a smaller beta only moves the state toward the new value. The update can replace a fact, but it cannot efficiently clear several associations during a context switch or decay memory in general.

Replacement still leaves forgetting unsolved. Mamba multiplies the previous state by a learned ratio before adding new information, which frees capacity but forgets every association together. Gated Delta combines this decay with DeltaNet’s selective replacement. A data-dependent scalar alpha between zero and one controls the previous state: `alpha = 1` gives the pure Delta rule, while `alpha = 0` clears the memory. Kimi Linear makes the control finer, learning a separate decay value for each channel. Under controlled comparisons, its authors reported better quality than full attention and presented it as a drop-in replacement with up to 6× higher decode throughput.

KimiK3 puts those memory choices into a hybrid backbone. It repeats 23 four-layer macrocycles. In each, three layers use Kimi Delta Attention and the fourth uses Multi-head Latent Attention. KDA keeps constant-state recurrent memory; periodic MLA layers retain full softmax retrieval over the token context. Gated MLA controls how much of each retrieved feature reaches the residual stream through element-wise multiplication with a gate projected from the input. The first layer in each macrocycle uses a dense feed-forward network; the others use a latent Mixture-of-Experts. That MoE has 898 experts: two shared experts process every token, and a router selects 16 of the remaining 896. The compressed latent space makes the expert pass faster and nearly halves the FLOPs.

The token context is not the only place information can be lost. Ordinary residuals add the embedding and every earlier layer’s output with equal weight, so later layers must produce increasingly large outputs to influence the sum, which can destabilize training. Attention Residuals, or AttnRes, give learned query-key weights to earlier depth-wise representations and let a block retrieve the ones useful for its current computation. Applying this at every layer would cost too much, so KimiK3 applies it after every 12 decoder layers. Across the 23 macrocycles, that produces eight AttnRes blocks. AttnRes addresses residual dilution and hidden-state growth; it adds roughly 2% inference latency and provides a 1.25× compute advantage. MLA retrieves from token context, while AttnRes retrieves from earlier depth.

Scale still matters, but each addition earns its capacity by solving a concrete storage or retrieval limit. Once a fixed-capacity associative memory reaches capacity, learned selection through gating, routing, or decay becomes necessary to evict associations. Periodic full-attention layers retrieve what the state could not keep, making attention the most effective selective-read mechanism in the design.
