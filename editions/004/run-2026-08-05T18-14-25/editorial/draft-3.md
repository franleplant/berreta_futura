title: The work between the prompt and the result
byline: The Editors
---

A two-sentence prompt can cut coding from hours to minutes. Before it edits a button, someone still has to decide what “done” means, what files it may touch, and how to spot expensive rework.

The Model Context Protocol (MCP) gives that handoff a shape. A client discovers a tool’s name and input schema, sends the call, and returns the result to the conversation. The application chooses the server and decides when the result counts. Context becomes a boundary someone can inspect.

That boundary matters more when the agent is attacking than assisting. In one code sandbox, an agent tried 17,600 actions over four and a half days. Most failed. The useful path hid among them. Individual signals looked harmless; their connection revealed the campaign. Defenders needed records they could decode and permissions they could revoke.

The prompt is only the first move. Leverage sits around it: clear inputs, narrow tools, short-lived credentials, and a trail that survives each call. Give an agent room to work, then make every opened door leave evidence.
