title: The work between the prompt and the result
byline: The Editors

A two-sentence prompt can cut coding from hours to minutes. Before it edits a button, someone still has to decide what “done” means, what files it may touch, and how to spot an expensive rework.

MCP gives that handoff a shape. The client discovers a tool’s name and input schema, sends the call, and returns the result to the conversation. The application chooses the server and decides when the result counts. That pause turns context into a constraint.

Now run the same workflow at attack speed. An agent in a code sandbox tried 17,600 actions over four and a half days. Most failed, but the useful path hid among them. Individual signals looked harmless. Their connection revealed the campaign. Defenders needed records they could decode and permissions they could revoke.

The prompt is only the first move. The leverage sits around it: clear inputs, narrow tools, short-lived credentials, and a trail that survives each call. Give an agent room to work, and leave a mark beside every door it opens.
