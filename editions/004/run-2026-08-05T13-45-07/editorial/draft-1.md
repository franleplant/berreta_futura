title: The Alarm Still Works
byline: The Editors
---

Somewhere in most office buildings is an alarm wired to call a guard station that closed years ago. Nobody rewired it, because nobody expected a burglar patient enough to try every door until one led to a line still open.

Every system defers some decision to a layer it does not inhabit. A protocol that hands a model's answer to the host, and calls what happens next the host's business, declines that judgment on purpose, so it stays small enough to be reused everywhere. A team that spends its newly cheap coding hours steering a plan instead of typing code is making the same bet, on purpose, because the decision that decides whether the result needs reworking was never the typing.

Both bets assume that somewhere downstream, a decision gets made. An agent that tried seventeen thousand things did not need to out-judge anyone. It needed one deferred decision that nobody was still making, a credential scoped for a task that had ended. It found that decision by trying every door, faster than any guard could watch.

The alarm still worked. The number on the other end had simply stopped being anyone's job.
