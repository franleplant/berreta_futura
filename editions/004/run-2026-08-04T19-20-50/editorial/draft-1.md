title: Downstream
byline: The Editors
---

An attempt that costs nothing to make still costs something. It only moves the cost downstream.

An agent that rooted a sandbox on someone else's infrastructure made 17,600 attempts over four and a half days, because failing cost it nothing. One of them reached a secret holding 136 keys, and a network opened behind it.

A two-sentence prompt into a coding agent produces something usable about half the time. The other half comes back for rework, and someone has to find what's wrong before they can fix it.

The two failures are not the same size. The sandbox's dead ends cost the agent nothing, because no one had to answer for any one of them; only the one that worked had to be found, by sorting through all the others first. The coding prompt's failure lands closer: it reaches a desk before the next attempt is worth making, and someone has to clear it before anything else gets built on it.

Free trying does not erase the cost of being wrong. It only decides whether that cost is paid once, by whoever sorts the pile for the try that mattered, or again and again, by whoever clears each miss first.
