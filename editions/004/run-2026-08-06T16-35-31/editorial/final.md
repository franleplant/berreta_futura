**The Eviction Policy**

A memory of fixed size must choose what to throw away. This is not a fact about neural networks. It is the whole situation.

The agent that took seventeen thousand actions against a company found nothing new. It found old holes cheaply. Speed does not invent flaws; it makes them affordable. The defence was never a smarter model. It was an admission policy, a scoped credential, a rule about what a template may evaluate.

The same shape everywhere. The protocol drops its session and hands you the thread instead. The bus stays deterministic and lets a job call the agent. The verdict is worth nothing until it rejects the handoff, blocks the edge, kills the run. A number in a report is a thermometer. You wanted a furnace.

Everyone rents the same brain. Nobody rents the constraint. The library of your own failures, each one now a test that cannot be failed twice the same way — that survives the model it was built to grade.

There is a joke at the end of the curve: the specification precise enough to eliminate all risk is the program. So stop planning at the flat part. Choose what to forget, deliberately, and write the choice down.
