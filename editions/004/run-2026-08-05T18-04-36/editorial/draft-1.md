title: "The Cost of a Shortcut"
byline: The Editors

A one-line credential gave an intruder cluster-admin access to two Kubernetes clusters within one second. The credential was ordinary. Its reach came from the way systems had been joined around it.

That same multiplication appears in quieter work. Writing code is only 25–50% of the time needed to ship a feature. Planning, review, testing, and rework remain. A detailed plan lowers expected pain, but only when it stops at the questions the team can answer.

Protocols make those questions visible. An MCP client discovers a tool, reads its schema, sends named arguments, and refreshes its registry when the server changes. The model can act because someone has described the available action and its limits.

The intrusion followed a darker version of that path. The agent searched, tested, decoded, and moved through whatever permissions and channels the infrastructure exposed. Each local success enlarged the next decision.

So the scarce resource is not faster execution. It is a trustworthy map of what execution may touch. Good context narrows a tool before use. Bad context turns one credential into a route across a company.

Speed earns its keep only when the person who set it loose can still point to where it is going.
