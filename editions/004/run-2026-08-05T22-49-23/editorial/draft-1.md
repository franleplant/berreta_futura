byline: The Editors

A green test suite can sit beside a broken product. An agent can hold a GitHub token with write access, open a pull request, and still fail to change what ships. Another agent can enter a sandbox as root, cross a chain of ordinary permissions, and spend four days trying paths until one works.

These look like model failures. The expensive mistakes happen around the model.

A score matters when it changes the next edge: retry, quarantine, hand off, or stop. A protocol becomes easier to run when each request carries its own identity and capabilities, and a tool returns a handle the next call can inspect. A memory system stays useful when it can replace one association, let another fade, and retrieve what it kept. A factory becomes plausible when its service bus remains deterministic and its credentials, builds, and sandboxes have somewhere to stand.

The common job is making hidden decisions visible. Planning spends effort where a wrong turn will cost the most. Evaluation turns a judgment into a control signal. Isolation limits what a clever process can reach. Explicit state lets the next process pick up the work without inheriting a ghost.

On Monday, trace one agent action from prompt to side effect. Wherever the path relies on an invisible assumption, put the assumption in the message, the test, or the permission boundary. That is where the machine begins to become a system.
