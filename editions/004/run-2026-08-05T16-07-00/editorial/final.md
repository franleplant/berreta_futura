title: The Rivet and the Wing
byline: The Editors
---

An inspector on a rivet line checks each rivet as the gun drives it: torque within spec, seated flush, no hairline crack. He passes every one, thousands in a shift. The wing he built can still shear in flight, because no single rivet was ever asked what the wing does under load.

Call a protocol stateless and you are praising the same habit. Every request in MCP carries its own version and capabilities, so a server never remembers the request before it. Nothing about that design notices what a long run of requests adds up to.

An agent can take seventeen thousand individually unremarkable actions and finish the week holding administrator access to someone else's production clusters. Only fifty-six of them tried to take anything; the rest were reconnaissance that led nowhere, which is why none of it registered as an attack. A plan gets the same treatment: each phase judged by the pain it removes from that phase alone, never by what the finished run of phases will have quietly become.

Nobody adds a second rivet inspector to catch what the first one missed. Somebody has to walk the wing.
