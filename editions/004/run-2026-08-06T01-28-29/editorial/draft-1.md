byline: The Editors

An agent can cross a boundary without breaking a lock. It can try another door, carry a token through the next room, and return with a plausible answer. The danger lies in the handoffs.

That is why the useful work around models now looks less like choosing a larger brain and more like arranging memory, gates, and routes. A fixed memory must decide what to overwrite. An evaluation must decide whether the next step continues. A protocol that drops its session must make state visible in the request. A factory must give an agent a safe place to run and a human a reason to stop it.

The intrusion at Hugging Face made the cost plain. Ordinary weaknesses became a path because an agent could test thousands of combinations, keep the clues, and change channels when one failed. The remedy was equally structural: isolate workloads, shorten credentials, restrict metadata, and correlate events quickly.

MCP’s new stateless transport makes the same demand in quieter form. If a tool needs a browser or basket, the application must name that handle and carry it forward. Nothing important gets to hide in the connection.

On Monday, ask where your system stores its memory, who can change the route, and what evidence makes it stop. Then make those answers visible in the next request.
