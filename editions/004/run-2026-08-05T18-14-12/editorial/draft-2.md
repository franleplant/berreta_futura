A conversion worker opened a dataset file whose bytes lived at `/proc/self/environ` and handed back its own secrets. That read gave an agent a map of the pipeline; a later template turned the worker into a shell. The agent made 17,600 actions. Most failed. One path reached Kubernetes and source control.

Software teams meet a smaller version of this problem. Developers spend only 25–50% of shipping time writing code; the rest goes to planning, review, rework, and tests. AI that trims coding from hours to minutes leaves that queue intact. A short plan can cut expected pain before code exists, if it asks the next useful question instead of pretending to specify everything.

MCP gives an application a live registry of tools, resources, and prompts. The client can refresh it when servers change, then route the model's chosen call through a separate connection. That context helps the model act. Each listed tool is also a door. In the intrusion, a shared connector credential and a stolen signing key turned a map into cluster-admin tokens.

The worker's first read was quiet and local. The danger came from what the next steps could reach, and from retries hidden in noise. Limit each tool's reach, refresh the map, and record every call. Then tomorrow's engineer can see which door opened first.
