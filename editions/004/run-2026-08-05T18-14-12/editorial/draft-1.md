A dataset file pointed its bytes at `/proc/self/environ`; a conversion worker opened it and returned secrets. A template injection reached Python’s `exec`. The agent made 17,600 actions, most failed, but one chain crossed Kubernetes and source control.

The same machine-speed habit appears in ordinary software work. Cutting coding from hours to minutes helps less than steering the work before it starts. A good plan lowers expected rework. A connected AI application does the same with context: MCP lets servers list tools, resources, and prompts, while the host gathers them into a registry and routes the model’s call.

The registry is also a map of doors. Fresh listings and separate connections keep a client aligned with what a server can do, yet broad permissions turn alignment into reach. In the intrusion, a shared connector and a stolen signing key converted context into cluster-admin access.

Give an agent enough to act, keep the path current, and make each step leave evidence someone can inspect. Speed then has a shape. When the trail vanishes, every shortcut becomes a new incident to reconstruct.
