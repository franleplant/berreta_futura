title: Intelligence Needs Surroundings
byline: The Editors
---

A model never arrives alone. It arrives inside a protocol, a runtime, a set of tools, a review policy, an evaluation loop, and a network full of assumptions. The surrounding system decides what the model can see, what it can do, and whether anyone notices when it is wrong.

This edition follows those surroundings at six scales. A frontier agent crosses infrastructure at machine speed. An evaluation layer turns attractive output into routing decisions. A software factory searches for the small amount of planning that removes most expected rework. A model architecture trades pairwise attention for recurrent state, selective retrieval, and sparse capacity. MCP defines the boundary between an AI application and the context it can reach, then revises that boundary so it can operate like ordinary stateless web infrastructure.

The model remains important. It is simply no longer an adequate unit of analysis. Capability becomes useful only when the system around it can expose state, preserve evidence, constrain action, and change course. The surrounding machinery is not support work. It is the product.
