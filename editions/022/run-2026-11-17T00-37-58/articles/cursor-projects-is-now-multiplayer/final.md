In September we introduced Projects, a way to direct a fleet of agents through a single coordinator. Today it's multiplayer: invite your teammates into a Project, and you plan, build and ship together, alongside all of your agents. Multi-agent systems have so far served one person. Projects is built for a whole team.

## One workspace

There's no shortage of collaboration software, but none for coding agents. In a Project, teams work side by side with their agents, sharing context, memory, and documents. A shared task board shows who's doing what, what each agent is working on, and the PR behind each task.

## Shared context

Agent context today is siloed per person, and newcomers must build it before putting agents to work. In a Project, each teammate keeps a one-to-one chat with their coordinator and worker agents, each with its own local context. Above that sits a shared layer: requirements docs, diagrams, tech specs, mockups. It's built once and grows with the team's work. A decision made in one chat reaches every agent in the Project, and a new teammate arrives to find context already configured and up to date.

We've seen this most clearly in on-call. Several of our teams now run their rotations in a shared Project. When one of our engineers recently took over from a teammate, their coordinator checked in first, then picked up where things stood. It already knew the work in flight, the unattended issues, the incidents and notes to hand off, and the channels, Linear boards and threads to watch. In-progress work can pass directly: the new person's agent simply takes it on.

## Agents talking to agents

Shared context lets teammates' agents plan around and unblock each other in real time, as people do. If an engineer adds reviews to the product page while a designer redesigns it, their coordinators spot the overlap early, and the reviews are built straight into the new design. If your feature reads from a database whose schema a teammate is changing, your agents agree on the order of work up front, so neither of you hits a merge conflict at the end.

## Getting started

Multiplayer Projects is rolling out in beta to all Cursor users starting today. Create a Project from the left-hand nav, then invite your teammates.
