# Social writing

This guide applies to magazine-authored social posts. It does not change source
articles, raw evidence, or exact quotations.

Social posts use the reusable Orwell-based method in `docs/WRITING_RULES.md`.
Other artifact types use that method only when the user asks.

## House rule

Never use the Unicode em dash character U+2014. Use a period, comma, colon,
semicolon, or parentheses instead.

## Thread rules

- Give each article its own thread.
- Use no more than five posts per article.
- Make each thread stand on its own.
- Name the source creator in the first post when space permits.
- Link every source used by the article.
- Put each link beside the claim or creator it supports.
- State magazine analysis in the magazine's voice. Do not post a source
  author's first-person `faithful_synthesis` as if the magazine wrote it.
- Ask for human approval of the exact copy.
- Ask again at the final publish action when the browser requires it.
