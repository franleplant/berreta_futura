# Writing rules

This is the repository's reusable Orwell-based writing method. It can guide
editorials, social posts, documentation, prompts, or other prose.

Do not assume that every artifact uses this method. Opening editorials and
social posts use it by default. Apply it to other work only when the user
asks.

For an opening editorial, use the method after finding the edition's own
argument. The rules should clarify a distinct unifying idea, set of ideas, or
emergent narrative. They must not turn the editorial into an article-by-article
summary or a prose table of contents.

## The six rules

1. Avoid clichés and familiar figures of speech.
2. Prefer short, common words.
3. Cut every word that does no work.
4. Use the active voice.
5. Prefer plain English to jargon.
6. Break any rule when breaking it makes the writing clearer.

## Editing test

Before delivery, ask:

- Is any phrase familiar enough to pass without thought?
- Can a shorter word carry the same meaning?
- Can any word or sentence be removed?
- Does the subject perform the action?
- Would an ordinary reader know every term?
- Would breaking one of these rules make the result clearer?
